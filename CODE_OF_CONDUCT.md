# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticise ideas and not people, and do not
harass anyone — in issues, pull requests, discussions, or anywhere you represent
the project. Maintainers may remove comments, and block people, who do not.

Report a problem privately to the maintainers through the contact listed on the
repository's profile (or GitHub's private vulnerability report if nothing else is
listed). Reports are kept confidential.
