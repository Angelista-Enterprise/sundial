# Sundial documentation

Sundial is local-first software for macOS: it records what you work on into a
private record on your Mac. Gnomon is the assistant inside it that reads the
record and talks to you.

## Use it

- [Getting started](getting-started.md): install, sign in, the setup page, your history.
- [Permissions](permissions.md): what each macOS permission lets Sundial see, and how to grant or reset it.
- [Models](models.md): give Gnomon a model, local or hosted, and what leaves your Mac.
- [Privacy](privacy.md): what is recorded, what is cleaned, how long it is kept, how to delete it.
- [Using Gnomon](using-gnomon.md): the board, the chat, notices, approvals, and Claude Code.
- [Troubleshooting](troubleshooting.md): symptom, cause, fix.
